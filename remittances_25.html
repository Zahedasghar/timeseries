Remittances Forecasting Analysis for Saudi.Arabia

6-Month Ahead Forecast with Multiple Methods

Executive Summary

This report provides a comprehensive 6-month forecast of remittances for Saudi.Arabia using multiple time series forecasting methods. We employ:

  • ARIMA (AutoRegressive Integrated Moving Average)
  • ETS (Exponential Smoothing State Space)
  • SNAIVE (Seasonal Naive with 12-month lag)
  • Ensemble (Combined forecast)

The best-performing model is selected based on accuracy metrics and used for final predictions.

7. Recommendations

Based on the analysis:

  1. Primary Model: Use ETS for official forecasts (lowest RMSE)

  2. Monitoring: Track actual remittances monthly and refit models quarterly

  3. Uncertainty: Consider the 80% prediction interval for planning purposes

  4. Seasonality: Account for seasonal patterns observed in the data

  5. Risk Factors:

    • Exchange rate fluctuations
    • Economic conditions in source countries
    • Policy changes affecting remittance flows
    • Global economic conditions

Appendix: Technical Details

Data Source

  • File: worker_remittances25.csv
  • Period: July 2010 - August 2025
  • Frequency: Monthly
  • Unit: Million USD

Models Used

  1. ARIMA: Automatic ARIMA with seasonal components
  2. ETS: Exponential smoothing state space model
  3. SNAIVE: Seasonal naive with 12-month lag
  4. STL+ETS: STL decomposition with ETS on seasonally adjusted series
  5. Ensemble: Equal-weighted average of ARIMA, ETS, and SNAIVE

Software

  • R version 4.x
  • Packages: fable, fpp3, tsibble, ggplot2
